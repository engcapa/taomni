## Changes

- Download the versioned official setup 2.941 URL with a pinned SHA256. The
  downloaded bytes were independently checked against the official `setup/sha512.sum`.
  Keep rejecting changed bytes before execution or environment publication.
- Apply default imports folding once the real document is reconciled, through
  the existing view-state lifecycle. Preserve explicitly expanded imports,
  cached state, caret/folds restoration and the live EditorView.
- Confirm the Java tab actually closes before the folding workflow reopens it.
- Compare native pointer geometry at pixel precision; retain DOM hit tests,
  deadline handling, moving-target waits and no input replay.

No product networking, proxy settings, IPC contracts or persistence formats changed.
The download change is restricted to hosted QA provisioning.

## Mail runtime follow-up

The failure begins during HTML-message loading; the final assertion after
composer closure detects it. The contact/composer assertions themselves pass.
Use the observed document's own ResizeObserver and MutationObserver constructors,
coalesce sizing into that window's animation frame, and give each loaded document
one owner for observers, pending frame, timers, image listeners and mailto listener.
Release the previous owner before attaching after load and release everything on
source change/unmount. Keep sandbox/CSP, height floor, appearance, search and
mailto behavior. No runtime errors are filtered or suppressed.

Two new mounted regression checks fail on the prior code: it constructs a parent
observer and does not release the prior document owner. After the fix, all 14
focused mail tests pass, including sandbox, mailto, resize scheduling/cleanup,
message body rendering, recipients and autocomplete. The workflow case additionally
checks that the selected message retains nonempty content and a visible
reader after composer reopen/close (native fixture: HTML iframe; browser stub:
plain text). Hosted WebView2 validation is required for
the cross-document delivery boundary.

The native monitor now also retains uncaught errors and unhandled rejections
from same-origin iframe windows, so moving observer ownership cannot move a
failure outside the assertion log. Eight focused Python contracts pass; a real
sandboxed Chromium iframe probe confirms error forwarding without cancellation.
The local mail workflow, production build (including refactor checks), and
catalog gate pass on the final mail change.

Hosted native executions use release QA binaries built from the fix branch. Native Windows
service setup and the macOS pointer path require these hosted results; local
browser stubs and Python contracts alone do not establish those boundaries.
