## Changes

- Download the versioned official setup 2.941 URL with a pinned SHA256. The
  downloaded bytes were independently checked against the official `setup/sha512.sum`.
  Keep rejecting changed bytes before execution or environment publication.
- Apply default imports folding once the real document is reconciled, through
  the existing view-state lifecycle. Preserve explicitly expanded imports,
  cached state, caret/folds restoration and the live EditorView.
- Confirm the Java tab actually closes before the folding workflow reopens it.
- Compare native pointer geometry at pixel precision; retain DOM hit tests,
  deadline handling, moving-target waits and no input replay.

No product networking, proxy settings, IPC contracts or persistence formats changed.
The download change is restricted to hosted QA provisioning.
