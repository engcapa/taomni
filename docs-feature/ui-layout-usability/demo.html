如何体验这个设计

本页独立运行，无需网络、安装依赖或启动 Taomni。上方一排用于切换演示场景和窗口尺寸，下方窗口是建议的产品布局。

  • 多 Tab：点“总览”，查看大卡片、搜索、类型筛选与工作组；点卡片回到对应内容。
  • 混合分屏：点“视图 → 左右并排 / 上下并排”，选择另一种内容。点面板标题切换焦点，左侧工具和 Tao 上下文跟随焦点。
  • 面板：左侧“会话 / 文件 / Git”复用同一位置；拖动面板右边缘调整宽度。打开 Tao，可切换聊天 / 便签 / 通知，选择固定或浮层。
  • 首页：固定“首页”按钮始终可见；从首页“返回工作”恢复分屏和原有上下文。
  • 标题栏：“新建”“视图”“总览”“Tao”都有名称；点“Taomni”查看低频应用操作。桌面窗口控制仅示意。
  • 键盘：Ctrl / ⌘ + Shift + H 打开总览，Ctrl / ⌘ + Shift + K 打开全局查找；Alt + Home 回首页；F10 切换专注。

Tab 可点击、关闭与拖动排序，邮件列表可切换，聊天可提交模拟消息，便签可在本次页面内编辑。刷新或“重置”恢复示例数据。

布局与交互演示不等于产品实现。连接、AI、文件操作、真实保存、原生窗口、截图采集和广播输入均未接入；完整规则见旁边的设计文档。
