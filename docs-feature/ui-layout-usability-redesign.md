# Taomni UI 布局完善与易用性重构设计方案

本文档针对 Taomni 现有桌面端 UI 布局的碎片化、多 Tab 拥挤混杂、面板层级不一、标题栏按钮混乱以及 Welcome 页面难以定位等核心痛点，提出整体重构设计方案。
配套交互原型演示文件位于：[`docs-feature/ui-layout-demo.html`](ui-layout-demo.html)（可用任意浏览器直接打开体验）。

---

## 1. 背景与现状痛点分析

Taomni 作为一款融合多场景（DevOps 终端、SFTP、数据库客户端、代码工作区、RDP/VNC 远程桌面、邮件客户端、LAN Chat 等）的超级桌面工具，随着功能逐步丰富，现有的 UI 布局显现出以下瓶颈：

### 1.1 多面板碎片化与交互割裂
- **左侧与上下文侧栏割裂**：最左侧有全局的 `Sidebar`（会话树与工具），而打开 SSH 终端时内部又有一个 Attached `SftpSidebar`；打开代码工作区时又有独立的 `ToolWindowRail` 和项目文件树/Git 差异面板。用户在不同 Tab 之间切换时，侧栏状态跳变剧烈。
- **悬浮球/气泡到处漂移**：原有的 `TaoRibbon` 采用四边边缘停靠的悬浮胶囊，容易遮挡终端右侧的命令输出、编辑器行号或系统窗口按钮，且拖拽位置难以精准持久化。
- **各面板缺乏统一的宿主规则**：有些面板在 Tab 内 Split，有些在全局抽屉，有些是模态弹窗，用户认知负荷较高。

### 1.2 多 Tab 场景下的“标签爆炸”与查找困难
- **单行水平标签栏容量有限**：当用户同时连接 10~20+ 个服务器终端、数据库和工作区时，Tab 标题被压缩得无法辨识，必须频繁左右横向滚动。
- **缺乏内容可视化感知**：用户无法直观了解各个后台 Tab 当前的状态（哪个终端还在跑命令？哪个查询已完成？哪个工作区有未提交代码？）。
- **现有 `...` 菜单操作链路过深**：目前的 `OpenTabsMenu` 虽然支持按目录分组和关键字过滤，但仍是纯文本下拉菜单，缺少全局“鸟瞰”与快速视觉识别。

### 1.3 会话类型混杂，无清晰视觉分层
- 所有 Tab（生产核心服务器、测试数据库、本地临时终端、工作邮箱、代码仓库）平铺在同一条线上，缺乏醒目的类型识别与环境分组。

### 1.4 窗口标题栏（ControlBar）职责超载与视觉拥挤
- 当前高度仅 32px 的 `ControlBar` 同时承担了：macOS 红绿灯占用、主菜单按钮、所有标签页、更新小红点、Tab 专属操作槽（`tab-action-slot`）、Tab 详情信息按钮、溢出 `...` 按钮、截图按钮及下拉菜单、窗口托盘按钮、系统最大化/最小化/关闭按钮。
- 图标紧密挤在右侧，语义不聚合，极易产生视觉噪音和误触。

### 1.5 Welcome 欢迎页定位困难
- 欢迎页目前仅作为初始标签存在（`type: "welcome"`）。当打开多个会话后，它被滚到最左侧视野之外；用户在工作中想要回到欢迎页快速发起新连接或查看最近项目时，很难快速找回。

## 2. 整体架构与布局重构建议

### 2.1 整体布局拓扑：现代化“双翼+沉浸主舞台”架构

综合 **VS Code、JetBrains IDEA 新 UI、Arc Browser、Warp、Cursor** 等优秀桌面应用的成熟长处，确立 Taomni 的三层视界骨架：

```
+----------------------------------------------------------------------------------------------------+
|  [Logo/Menu] [🏠主页] [ Tab 1 (SSH) ] [ Tab 2 (DB) ] [ Tab 3 (Code) ] [+] ...  [⊞预览] [📷] [✦Tao] [— □ ✕] |  <- 干净的三段式标题栏
+------+-----------------------+----------------------------------------------------+----------------+
|      |                       |                                                    |                |
|      |                       |  [上下文微操作条 Context Sub-Bar: 状态/编码/联动]  |                |
|      |                       +----------------------------------------------------+  Tao 统一副驾  |
| 活   |  左侧工作抽屉         |                                                    |                |
| 动   |  (Collapsible Drawer) |  主舞台工作区 (Main Stage Viewport)                |  (AI Copilot + |
| 窄   |  - 会话树 (Sessions)  |  - 沉浸式终端 (Terminal)                           |   随手记 Notes + |
| 轨   |  - 联动 SFTP 浏览器   |  - 数据库查询与结果集 (Database)                   |   统一通知 Inbox) |
|      |  - Git 分支与改动     |  - 代码工作区 (Code Workspace)                     |                |
| (44px|  - 数据库架构对象     |  - 统一邮件 (Mail)                                 |  (320px, 可折叠 |
| 极简)|  - 实用工具/隧道      |  - 欢迎仪表盘 (Welcome)                            |   可停靠/可浮动)|
|      |                       |                                                    |                |
+------+-----------------------+----------------------------------------------------+----------------+
|  底部极简状态栏 (StatusBar: 状态就绪 · 当前会话 · 快捷键导航提示)                                      |
+----------------------------------------------------------------------------------------------------+
```

### 2.2 核心面板融合与职责边界

#### 1) 为什么不把 SFTP / Git 都塞进 Tao？
- **Tao 的定位**：全域智能副驾与个人伴侣（**AI Copilot + 灵感便签 Notes + 统一消息通知中心 Tao Inbox**）。
- 如果把 SFTP 文件树或 Git 审查也硬塞进 Tao，会导致：
  - 侧边栏宽度冲突（文件树和差异对比需要更宽的视图）；
  - 交互心智混乱（用户找“远程服务器上的文件”却要在“AI 对话框”里翻找）；
  - 无法兼顾“边看文件边让 AI 解释”的多任务并存诉求。

#### 2) 左侧：统一活动窄轨（Activity Rail）+ 上下文抽屉（Context Drawer）
- **左侧 44px 极窄图标轨**：
  - `🏠 Home / Welcome`：**永久固定在顶端**，任何时刻一键直达欢迎主页。
  - `🖥️ Sessions`：服务器与连接目录树。
  - `📂 SFTP Files`：直接与当前激活的 SSH 终端**联动绑定**。不再在终端内部切出一块局部的 `SftpSidebar`，而是点开左侧 SFTP 抽屉即可直接浏览当前机器的远程目录，一键拖拽上传/下载。
  - `🌿 Git`：当前工作区的代码分支、未暂存更改与提交。
  - `🗄️ Database`：库表结构树、视图与存储过程。
  - `🛠️ Tools`：端口转发隧道、SocksCap、MFA 令牌等。
- **一键折叠（`Cmd/Ctrl + B`）**：点击当前激活图标或按快捷键可瞬间折叠整个左侧抽屉，让终端或编辑器享有 100% 纯净宽度。

#### 3) 右侧：Tao 统一副驾面板（替代四处漂移的悬浮球）
- **告别边缘悬浮小胶囊**：全面废弃原有的 `TaoRibbon` 浮动球，改为右上角常驻入口及快捷键 `Cmd/Ctrl + J` 控制的统一右侧抽屉。
- **三 Tab 结构**：
  - `✦ Copilot`：自动感知当前主舞台正在查看的会话（显示“已绑定会话: prod-k8s-node-01”），提供智能命令补全、SQL 优化、日志诊断与代码解释。
  - `📝 Notes`：会话专属备忘录与全局随手记。
  - `🔔 Inbox`：全局统一通知中心（包括：后台耗时编译完成、新接收的紧急邮件、定时任务告警等，带有未读呼吸红点）。
- **展示模式**：支持停靠分栏（Docked）与悬浮遮罩（Floating Overlay）两种模式自由切换。

## 3. 多 Tab 创新交互：大预览卡片网格切换器 (Visual Tab Overview Grid)

针对打开 10~30 个 Tab 时极易迷失的问题，本方案借鉴 **macOS Mission Control / Safari Tab Overview / Windows 任务视图 / Edge 垂直标签** 的精髓，引入 **“大画廊预览网格 (Visual Tab Overview Grid)”**。

### 3.1 触发方式
- **快捷键**：`Ctrl + Tab`（快速按键轮巡）或 `Cmd/Ctrl + Shift + O`（直接呼出全屏网格）。
- **界面按钮**：标题栏右侧显眼的 `[预览网格 ⊞]` 按钮。

### 3.2 交互形态与核心能力（见 HTML 原型演示）
1. **沉浸式半透明毛玻璃画廊**：
   - 界面平滑展开全屏覆盖层，所有打开的会话以 **大尺寸卡片（320px+ 宽度）** 优雅网格平铺展示。
2. **实时内容缩略预览 (Live Snapshot Preview)**：
   - **终端卡片**：直接显示终端最新的 5~8 行真实输出或执行中的命令，并在右下角打上 `● 运行中` 的动态脉冲绿点。
   - **数据库卡片**：直接显示最后编写的 SQL 语句和结果集前 3 行数据。
   - **代码工作区卡片**：显示当前正在编辑的文件名及语法高亮代码切片、待提交文件数量。
   - **邮件卡片**：显示最近 2 封未读邮件的标题与摘要。
3. **毫秒级即时搜索与过滤**：
   - 顶部自动聚焦搜索框，用户可直接键入：主机 IP（如 `10.244`）、服务器别名（`k8s`）、分支名（`feat`）、SQL 表名或会话类型。
   - 敲击字母瞬间，卡片动态过滤筛选；按 `Enter` 键立刻切入首选卡片并关闭浮层；按 `Esc` 退出。
4. **分类过滤胶囊 (Category Pills)**：
   - 顶部一键过滤：`全部 (12)` | `终端 SSH (6)` | `数据库 (3)` | `代码工作区 (2)` | `邮件 (1)`。
5. **卡片内快捷操作**：
   - 鼠标悬浮在卡片上，右上角浮出快捷操作：`✕` 一键关闭会话、`📌` 固定会话。

## 4. 不同类型 Session 的 Tab 切分与摆放策略

为避免各类会话在标签栏中混杂成一锅粥，采用 **“固定基座 + 类型语义识别 + 分组空间 (Spaces)”** 的三层组织模式：

### 4.1 标签栏分区规则
1. **左侧固定区 (Pinned Base)**：
   - **🏠 Welcome 主页按钮**：永远固定在标签栏最起始位置（紧靠主菜单），带有明显的轮廓与强调色，不随标签滑动而位移。
   - **常驻应用（可选固定）**：如全局工作邮箱、LAN Chat。
2. **活动会话区 (Dynamic Session Tabs)**：
   - **视觉语义着色 (Type Badges / Accent Dots)**：
     - **SSH / 终端**：亮青蓝色（Cyan Blue `#38bdf8`），带终端小图标。
     - **数据库 / 数据引擎**：翠绿色（Emerald Green `#4ade80`），带数据桶图标。
     - **代码工作区**：优雅紫色（Purple `#c084fc`），带代码分支图标。
     - **RDP / VNC 桌面**：暖橙色（Orange `#fb923c`），带显示器图标。
     - **工作邮件**：琥珀黄色（Amber `#fbbf24`），带信封图标。
3. **环境与目录聚合胶囊 (Spaces / Group Folders)**：
   - 支持将同属于某一业务环境的会话打包为胶囊（如 `[生产集群-华北 (4)]`、`[本地测试 (2)]`），在水平栏上可一键折叠或展开，减少视觉横向占用。

### 4.2 标签栏与内容区的职责解耦：下沉“上下文操作条”
- 原先在标题栏右侧的 `tab-action-slot`（如当前终端的编码切换、上传下载、广播输入、复制会话）**彻底移出标题栏**。
- 改为在主舞台顶部提供一条精致高度（30px）的 **“上下文微操作条 (Context Sub-Bar)”**：
  - 显示当前连接的真实 IP/域名、连接延迟（如 `18ms`）、字符编码。
  - 右侧提供：`[📂 联动 SFTP]`、`[⚡ 广播输入]`、`[📋 复制会话]`、`[🪟 分离为独立窗口]` 等专属操作。
  - 这样既让特定 Session 的操作近在手边，又彻底释放了标题栏的宝贵空间。

## 5. 窗口标题栏（Window Chrome）重构与清晰度设计

原先的混乱源于“不同层级的功能没有分组，全部平铺在同一条线上”。重构后的标题栏采用严谨的 **“三段式栅格 + 功能语义聚合簇”**：

### 5.1 左段：系统与品牌导航
- **macOS**：保留原生红黄绿三色交通灯，接着是 Taomni 极简品牌 Logo 与主菜单入口。
- **Windows / Linux**：左上角极简 Logo + 主菜单按钮 + 侧栏展开/收起按钮。

### 5.2 中段：标签流与全局命令栏
- **居中标签栏**：标签采用圆角轻量卡片风格，Active 标签高亮且有轻微上浮阴影，非 Active 标签低饱和度。
- **右侧新建按钮 `+`**：点击弹出下拉菜单，支持一键创建本地终端、远程 SSH、SQL 查询、代码工程等。

### 5.3 右段：功能语义聚合簇（3 组独立小岛）
通过细微的边框与间距，将原本凌乱的图标聚合成 3 个功能岛：
1. **视图与布局组 (View & Layout Cluster)**：
   - `[⊞ 预览网格]`：呼出大预览卡片画廊。
   - `[◫ 分屏布局]`：切换单屏、左右分屏、上下分屏、四宫格。
2. **快捷实用工具组 (Tools Cluster)**：
   - `[📷 截图]`：集成系统截图、延时截图、长截屏入口。
3. **智能体与告警组 (Tao & Alerts Cluster)**：
   - `[✦ Tao]`：展开右侧 Copilot 面板，附带未读通知呼吸红点。
4. **窗口控制组 (Window Controls on Win/Linux)**：
   - 最小化、最大化、关闭（符合操作系统原生热区习惯）。

## 6. Welcome 欢迎页的便捷定位与易用性增强

为了让用户随时随地秒回基地，设计**四重直达机制与增强仪表盘**：

### 6.1 四重秒级直达机制
1. **左侧 Activity Rail 顶部常驻 Home 图标**：左侧图标窄轨第一位永远是高亮的 `Home` 房子图标，点击立刻切回 Welcome。
2. **TabBar 最左端固定 Home 标签**：永远停靠在标签栏开头，不随任何滚动条滚动，一眼即见。
3. **全局快捷键**：`Cmd/Ctrl + Shift + H` 任意界面随时直达。
4. **无 Tab 自动退回机制**：当用户依次关闭所有工作 Tab 时，系统不会留下空黑屏，而是平滑过渡回 Welcome 页面。

### 6.2 Welcome 仪表盘信息架构升级（见 HTML 原型展示）
- **顶部极速连接框 (Omni-Connect Bar)**：直接支持粘贴 `ssh user@host:port` 或本地路径，敲回车即可直连。
- **未关闭会话一键恢复条 (Resume Bar)**：当检测到上一次非正常退出或历史会话时，顶部横幅显示 `上次未关闭的 4 个工作会话，一键全部恢复`。
- **最近活跃会话大卡片 (Recent Sessions)**：以磁贴卡片展示最近使用的服务器/数据库/工作区，清晰呈现主机 IP、端口、在线状态与最后活跃时间。
- **快捷动作启动台 (Quick Launchers)**：大图标直连：新建终端、新建查询、打开代码目录、新建网络隧道。

## 8. 待与用户讨论的关键决策点 (Decision Points for Discussion)

在推进后续开发实现前，以下 3 个关键体验设计建议与用户讨论：

### 决策点 1：左侧工具栏模式选择
- **选项 A（现代 Activity Rail 窄轨，推荐）**：如原型所示，最左侧仅占 44px 极窄图标轨，点击图标展开/收起具体抽屉。工作时可完全一键折叠，终端和代码享受全屏无干扰视野。
- **选项 B（传统全侧栏）**：左侧保持固定 240px 侧栏，通过顶部切换 Tab（会话树 / SFTP / 工具）。
- *建议采用选项 A，更适合同时使用终端、数据库和编辑器的复合场景。*

### 决策点 2：Tao 智能副驾的停靠交互形态
- **选项 A（右侧抽屉，推荐）**：彻底取代四处漂移的悬浮胶囊 `TaoRibbon`，统一放置在右侧（快捷键 `Cmd+J`），可分栏停靠（Pin）也可覆盖浮层（Float）。
- **选项 B（保留四边悬浮胶囊）**：保留原有边缘可拖拽小球。
- *建议采用选项 A，能彻底消除终端右侧文本遮挡问题，提升界面专业度与稳定性。*

### 决策点 3：多 Tab 大预览网格的呼出习惯
- **选项 A（全屏沉浸式毛玻璃画廊，推荐）**：类似原型中的半透明模糊全屏卡片流，信息丰富，能看清终端最后输出和 SQL 结果，直观震撼。
- **选项 B（居中弹窗 Switcher，类似 Alt-Tab）**：尺寸相对较小的居中卡片弹窗。
- *建议采用选项 A，对于 10+ 以上多会话的高级用户，全屏大卡片能带来质的效率飞跃。*

1. 点击顶部 **`[预览网格 ⊞]`** 或按快捷键 `Ctrl+Tab`，体验大卡片实时预览、搜索过滤与即时跳转；
2. 点击左侧活动轨图标（Home、Sessions、SFTP、Git、DB）体验抽屉联动；
3. 点击右上角 **`[✦ Tao]`** 或按快捷键 `Cmd+J` 体验右侧 Copilot、便签与通知抽屉；
4. 点击任何 Tab 或左上角 **`[主页]`**，体验 Welcome 仪表面板随时秒切。
