# 滚动截图、标注颜色与贴图操作

本轮在现有截图工具上交付三组行为。滚动截图支持手动和自动，可在采集期间切换；标注增加橙、青、紫、粉、灰、黑六种预设（共 11 种），支持系统颜色选择器和 HEX 输入；贴图增加复制、保存、缩放、透明度、收起、收藏及收藏列表。

## 交互与保留行为

- 手动模式隐藏选区遮罩，用户在边框内用滚轮或触控板缓慢向下滚动，停顿和抵达底部均不会结束会话。完成保留结果，取消保留原选区和标注。手动模式不创建 Enigo，不依赖 macOS 辅助功能权限；屏幕录制权限仍由实际截图路径要求。
- 自动模式每次滚动重新定位到选区，延长静止判定，无法匹配时等待重绘后重试。大步滚动失败时回退并减速；仍无法拼接或一直无法触发滚动时转入手动，不把第一屏或不完整内容静默当作成功的长截图。错过重叠时保留最后可靠锚点并提示用户稍微向上滚回。
- 新颜色作用于后续标注，选中已有标注后改色可撤销；不重绘未选中的旧标注。HEX 不合法时保留有效颜色，失焦恢复显示。
- 贴图保持独立、置顶、可拖动。工具栏提供复制、保存、收藏、收起、设置和关闭。右键有意改为打开设置；Esc 先收起设置，再关闭贴图。双击关闭，Shift+双击收起，收起后点击展开按钮恢复。
- 滚轮或 +/- 缩放，Ctrl/Cmd+滚轮调透明度；0 或中键重置。缩放和透明度仅影响显示，复制、保存、收藏均使用原始 PNG。收起后为 64×64 逻辑像素的缩略图，展开恢复此前窗口尺寸、缩放和透明度。
- 收藏保存在应用数据目录的 `screenshot-favorites/<uuid>/`，包含原图、缩略图和元数据。用临时目录写入再重命名发布，入口只接受规范 UUID。临时截图和贴图关闭不删除收藏。截图按钮下拉菜单的“截图收藏”支持查看、重新贴图、刷新和确认移除；删除收藏不影响已经打开的独立贴图。
- macOS 透明窗口依赖 Tauri 的 `macos-private-api` 与 `app.macOSPrivateApi`；三平台 native 检查真正的桌面合成像素，不能用 CSS opacity 代替透明窗口证据。

## 参照

采用 Snipaste 已公开的贴图交互：滚轮缩放、Ctrl/Cmd+滚轮透明度、缩略图模式、复制/保存与快捷键。参考官方文档：https://docs.snipaste.com/zh-cn/getting-started 和 https://docs.snipaste.com/zh-cn/key-bindings 。本轮的持久收藏列表用于关闭或重启后找回用户主动收藏的截图。
