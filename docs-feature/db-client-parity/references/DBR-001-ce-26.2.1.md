## 场景观察

| 场景 | 观察 |
|---|---|
| 主窗口 | 菜单 File / Edit / Navigate / Search / SQL Editor / Database / Window / Help。左侧 Connections / Projects（带按名过滤），左下 Files（Bookmarks、Dashboards、Diagrams、Scripts），右侧 AI Chat。空编辑区显示常用快捷键提示。主工具栏有 SQL、Commit、Rollback、事务模式指示和当前库选择器。状态栏：时区、Writable、Smart Insert、光标位置、选区 |
| 建连接 | Database → New Database Connection：驱动磁贴网格，按 All / Popular / SQL / NoSQL / Analytical / Files / Embedded / Timeseries / Hadoop / Full-text / Graph 分类，可按标题或评分排序。选 MariaDB 后进入 Main / Advanced / Driver properties 页和 “+ SSH, SSL, …”；Connect by Host 或 URL（URL 随字段实时生成）；Authentication、Save password、Connection details。Test Connection 时如果缺驱动，先弹 Download driver files，下载后显示 `Connected (27136 ms)`、服务端与驱动版本。连接默认命名为 `host:port` |
| 编辑器 | New SQL script 打开 `<库> Script` 标签；每个脚本/表编辑器默认使用独立的连接上下文（“Open separate connection”） |
| 执行脚本 | Alt+X。默认**遇错停下**并弹出 Execution Error：`SQL Error [1146] [42S02]: (conn=19) Table ... doesn't exist`，按钮 Details / Stop / Retry / Skip / Skip all。Skip 后继续执行。每个结果集一个标签（`<表> 1`、`<表> 1 (2)`），另有 `Statistics 1` 标签：Queries、Updated Rows、Execute / Fetch / Total time、Start / Finish time |
| 执行当前语句 | Ctrl+Enter 只执行光标所在语句（以空行/分号定界），复用当前结果标签（未 pin 的标签被替换） |
| 数值显示 | 默认按 locale 格式化：`4,350`、`4,393.5`、`1.5`，不保留 DECIMAL 的定标 |
| Explain | Ctrl+Shift+E 只对当前语句执行，结果标签 `Execution plan - 1`，树形表格列 Type / Name / Cost / Rows（select → filesort → temporary_table → nested_loop → table），下方显示对应 SQL |
| 结果集布局 | 顶部是 SQL 过滤栏（显示原始查询 + “Enter a SQL expression to filter results”），左侧竖排视图切换（Grid / Text / Record 等），右侧 Value 面板，底栏有 Refresh、Save、Cancel、Export data、fetch size（200）、`N row(s) fetched - <耗时>, on <日期> at <时间>` |
| 排序 | 列头排序图标与右键 Order → `Order by <列> ASC/DESC`。设置 DESC 后结果变为 200、199…（服务端/客户端归属未确认） |
| 过滤 | 右键 Filter：Find and Replace、Filter by value、按单元格值 `= / <> / > / <`、Custom 条件。选择后过滤栏显示条件，查询被包装为 `SELECT * FROM (<原查询>) WHERE <条件>` **重新发往服务端**。清空过滤栏并回车即恢复 |
| 导出 | 底栏 Export data → Data Transfer 向导：Export target（格式：Database、CSV、DbUnit、HTML、JSON、Markdown、SQL、Source code、XML…）→ Extraction（Query the database / Use fetched rows、Open new connection(s)、Selected rows/columns only、Select row count）→ 格式设置（扩展名、分隔符、Header 位置/格式、引号与转义、NULL string、Format numbers…）→ Output（Copy to clipboard、目录、文件名模式、Show finish message、导出后打开目录、执行后续进程）→ Confirm 汇总，可 Save as task。导出到剪贴板：CSV 表头加引号，共 202 行，保留当前 DESC 排序 |
| 取消长查询 | 执行中结果区叠加 “Execute query” 进度与 Cancel 按钮，底栏 Cancel 也可用。取消后结果区显示一行 `slept = 0, marker = done`（MariaDB 中 SLEEP 被中断时应返回 1，这里的语义待复核）；随后查 processlist，没有残留的 sleep 会话 |
| 断线恢复 | `kill connection connection_id()` 之后，下一条语句**直接成功**，connection id 变为新值（25），没有看到错误或提示 |
| 事务 | 默认 Auto-Commit。Database → Transaction mode：Auto-Commit / Manual Commit (None) / Smart commit mode + 四种隔离级别；另有 Transaction log、Pending transactions。切到 Manual 后工具栏显示 `None`，悬停提示 “Switch to auto-commit”。有未提交语句时断开连接：每个编辑器上下文各弹一次 “Commit changes during disconnection”（Yes / No / Cancel，可勾选 Do not ask me again） |
| 危险语句确认 | 脚本中含 DROP 时弹出 “Execute drop queries” 确认（Yes To All / OK / Cancel），逐条显示语句 |
| 导航树 | 连接 → Databases / Users / Administer / System Info；库 → Tables（显示磁盘大小，如 16K）/ Views / Indexes / Procedures / Packages / Sequences / Triggers / Events |
| 表编辑器 | 双击表打开 `dbr_parity_item` 标签，顶层页签 Properties / Data / Diagram。Properties 头部：Table Name、Engine、Collation、Description、Auto Increment、Charset、Partitioned；左侧子页签 Columns、Constraints、Foreign Keys、References、Triggers、Indexes、Partitions、Statistics、DDL、Virtual。Columns 表：Column Name、#、Data Type、Not Null、Auto Increment、Key、Default、Extra、Expression |
| 数据编辑 | Data 页签双击单元格即可行内编辑，底栏 Save / Cancel 变为可用，悬停 Save 提示 “Apply changes”。点击 Save **直接写入，没有 SQL 预览或确认**；从另一个脚本查询确认 11.75 / 22.25 已持久化。右键 Edit 子菜单中没有预览项（Generate SQL 在右键菜单中单独存在） |
| 退出 | 关闭窗口时弹 “Exit DBeaver — Are you sure?”（Yes / No，可勾选 Do not ask me again） |

## 与 DBVIS-001 的对照要点

| 维度 | DBeaver CE | DbVisualizer Pro | 取长初判 |
|---|---|---|---|
| 脚本遇错 | 默认停下并弹框（Stop / Retry / Skip / Skip all） | 默认继续执行，只在 Log 中逐行显示状态 | 两种都要：默认停下 + 行内可选继续，Log 表格取 DbVisualizer |
| 执行日志 | Statistics 汇总标签 | Log 表格逐语句（状态、耗时、行数、错误码）+ 汇总 | dbvis |
| 默认事务 | Auto-Commit；Manual 时断开前提示 | Auto Commit OFF（Development）；状态栏计数 + 执行后/关闭前提示 | 状态栏计数与关闭提示取 dbvis，事务模式菜单取 DBeaver |
| 危险语句 | DROP 执行前确认 | 未观察到 | dbeaver |
| 结果过滤 | 服务端 SQL 条件（重新查询） | 客户端 Quick Filter（跨列子串） | merge：Quick Filter + SQL 条件栏 |
| 排序 | 右键 Order ASC/DESC、列头图标 | 列头单击切换，客户端排序，“Reload with Sorting as ORDER BY” | merge |
| 导出 | Data Transfer 任务化向导、格式多、可存为任务 | 4 步向导，含预览，目的地可为 SQL 编辑器 | dbeaver 为主，补 dbvis 的预览与编辑器目的地 |
| 数据编辑保存 | 直接写入，无预览 | 直接写入，无预览 | 两者都没有预览；Taomni 目标为“保存前 SQL 预览 + 确认”（当前 `QueryGridCommitPayload` 流程的行为待 P0 核对） |
| 断线恢复 | 静默重连 | 失败一次后自动取新连接，Log 有 INFO | 取 dbvis 的可见提示，并补充“事务已丢失”的提醒 |
| 数值格式 | locale 格式化 | 保留定标（10.50） | dbvis（数据库客户端应显示原值） |
