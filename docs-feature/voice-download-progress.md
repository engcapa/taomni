# 语音模型下载窗口、进度与续传

## 用户行为

模型弹窗改为最大 960px 的响应式布局：语言与代理并排、Base/Small/Medium 分列，窄窗口自动换行。内容独立滚动，关闭按钮保留在右上角。

每个模型显示固定版本的官方完整下载地址，支持点击地址、复制地址和“浏览器打开”。这些地址由 Rust 模型目录生成，与应用下载所用 URL 完全一致。浏览器/下载工具得到 `.bin` 后可离线导入；浏览器遵循其自身代理设置，不继承应用内单独配置。

下载状态保存在后端，包含任务 ID、单调递增修订号、模型、阶段、已接收字节和总大小。窗口关闭不会终止下载；重新打开或从其他窗口查看，会读取当前快照并继续订阅进度，另有定时快照兜底。旧快照不能覆盖新事件。下载或校验期间禁用重复下载/导入/检查。

窗口显示连接中、下载中、导入中、校验中、完成、失败或已取消，以及 MB 和百分比。传输到 100% 后仍显示“正在校验”，SHA-256 通过并发布最终文件才显示完成。

## 取消和断点续传

- 下载期间点击“取消下载”中止当前任务，保留 `.bin.part`。取消按任务 ID 匹配，迟到的取消不会停止新任务；取消网络请求/等待读取后，先刷写文件再更新状态。
- 重新点击“继续下载”从实际文件长度续传；应用重启后也能发现断点。断点属于模型的哈希版本目录，不跨版本拼接。
- 请求使用 `Range: bytes=N-`；206 响应必须具有匹配的 Content-Range 起点、终点及总大小。服务器返回 200 表示没有执行 Range，截断旧文件后重新完整下载，不能错误追加。错误的 Content-Range 拒绝写入，保留原断点。
- 网络中断/超时保留断点，用户重试；没有自动循环重试。下载仍有原来的总超时限制。
- 校验失败删除损坏下载，避免重复续传坏文件。无论从零下载还是续传，最终必须通过大小和 SHA-256 校验；已有有效模型及旧版本不被失败下载覆盖。
- 校验阶段不提供取消按钮；网络传输已结束，发布前检查取消标志。离线导入使用单独临时文件，不覆盖已有下载断点，成功导入后清理同版本断点。

## 验证与边界

前端测试验证准确的复制/打开 URL、重新打开恢复进度、乱序快照、100% 后仍需校验、任务取消/重试及重复点击保护。浏览器 `TC-VOICE-004` 使用显式延迟 fixture 验证进度/取消/恢复以及宽窄截图；`TC-VOICE-001/002/003` 保留模型、语言与代理流程。

Rust 本地 HTTP 服务测试验证实际取消后的文件长度、Range 续传、服务器忽略 Range 时完整重下、错误 Content-Range 不改原文件、完整校验/发布与旧任务取消隔离。代理路由的既有测试继续保留。

浏览器 fixture 不是真实下载；本地小文件协议测试不等于 Win11 上完整下载验证。系统浏览器打开、OS 剪贴板和真实 Hugging Face/CDN 的大文件取消/续传，请在 Win11 真机补验；沿用现有原生打开 URL 与剪贴板公共入口。
