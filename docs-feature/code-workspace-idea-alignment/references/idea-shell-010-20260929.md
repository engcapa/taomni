## 视觉观察及适用边界

本轮像素边界约：顶部 54px；左右 rail 各约 54px；Project 左边 x=54、右边 x=510；editor 左边 x=516；底窗打开时顶边 y=660，状态栏顶边约 y=999。它们是本轮配置的测量，不是跨平台 CSS token。焦点工具的 rail/分类标签为蓝色，失焦但显示的工具采用灰色；最大化不隐藏 rails。

本轮未采：工具停靠拖放、浮动窗口、侧窗上下分组、IDE 重启布局持久化、OS 屏幕阅读器、IME、Windows/macOS 或出厂默认 profile B。实现的 resize/cancel/persistence/failure 采用 Taomni 明确适配合同，不冒称 IDEA 实测。IDEA 源码无本轮需解释的隐藏规则，未克隆源码。

纠正旧摘要“再次按下隐藏”的过度简写：**工具隐藏时打开并聚焦；可见但失焦时聚焦；可见且有焦点时再按才隐藏**。空 editor 的 S1a 不证明 Esc 成功返回 editor。以上只构成 IDEA 参照，不构成 Taomni native/comparison 通过。
