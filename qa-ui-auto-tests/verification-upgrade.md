# 用例行为契约升级与 Linux 验证

范围：`cases/**/*.testcase.yaml` 的 231 个用例，包括 `cases/auto`。
`scopes/` 是历史/专项选择副本，不作为第二套正式用例维护。

## 验收标准

每个用例必须关联需求、真实操作、关键状态转换、精确业务结果和运行证据。
操作成功、截图已生成、控件被触达、测试标题描述了某行为均不能替代结果断言。
文本包含适用于非确定性输出中的必要消息；完整内容不变、顺序、数量、保存结果
等确定性需求必须使用精确断言。等待带业务条件的 selector 可作为状态检查。

用例中的 `verification` 声明需求与步骤对应关系，静态校验检查引用和检查类型，
运行报告逐项关联实际步骤结果。静态检查不判断需求本身完整性，也不代替人工审阅。
视觉与原生边界单列检查，截图留存不自动算视觉通过，browser 不算 native 通过。
Windows/macOS 未执行部分单列，不扩大 Linux 结果的适用范围。
